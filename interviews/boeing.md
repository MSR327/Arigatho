## 2025-26 season · Associate Software Engineer (Associate Multimedia Support Engineer) · IIT Kanpur · on-campus

An online assessment with computer graphics MCQs, C++ DP coding and OpenGL, then a single online technical interview; no HR round.

### Online assessment

Computer graphics MCQs, C++ coding focused on DP, and OpenGL.

**Computer graphics MCQs**

MCQs on rasterization, rendering pipeline stages, texture mapping, lighting models and simulator protocols.

<sub>Topics: Other</sub>

**C++ DP coding**

DP-based C++ coding problems. Exact questions not given.

<sub>Topics: DP</sub>

### Technical interview

Single online round, conversational, deep on computer graphics.

**Graphics pipeline stages**

Explain the stages of the graphics pipeline in detail.

<sub>Topics: Other</sub>

**Vertex vs fragment shaders**

How do vertex and fragment shaders differ? Walk through a shader program.

<sub>Topics: Other</sub>

**OpenGL basics and shading techniques**

OpenGL basics and the different types of shading techniques.

<sub>Topics: Other</sub>

**Modelling a glass**

How would you model a glass, and which buffers would you use?

<sub>Topics: Other</sub>

**Real-time cloud rendering**

How would you simulate realistic cloud rendering in real time?

<sub>Topics: Other</sub>

**Airport layout rendering optimisation**

Discuss approaches to airport layout in rendering optimisation.

<sub>Topics: Other</sub>

**Computer graphics projects**

Questions on your own computer graphics projects.

**Tips:** Study computer graphics lecture series covering rendering, shaders and pipeline. · Practise C++ DP regularly. · Have one or two solid projects in your core domain.

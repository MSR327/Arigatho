Eliminative; needed at least 80% to qualify; ample time.

**Aptitude test**

Basic aptitude, logical reasoning and analytical questions. Exact questions not given.

### Python challenge 1

Easy DSA in Python with detailed comments explaining logic and edits made while testing.

**Easy DSA problem in Python**

An easy-level DSA problem to be solved efficiently passing all test cases, with explanatory comments. Exact problem not given.

Medium-hard difficulty with clean code and comments required.

**Strings and recursion problem**

Compare two AI-generated responses and justify the choice.

**Compare two AI answers to a recursion prompt**

Given two AI-generated responses to a recursion-based coding prompt, decide which is better and explain why in terms of code quality and logic.

<sub>Topics: ML/AI, Recursion/Backtracking</sub>

**Past experience and remote work**

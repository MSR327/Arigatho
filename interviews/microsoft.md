## 2025-26 season · Data Scientist · IIT Kanpur · on-campus

Online assessment, then two interview rounds; nine M.Tech CSE students were shortlisted for interview.

### Online assessment

Three questions in 1.5 hours: one DSA, one SQL, one ML coding in a Jupyter notebook.

**Count consecutive-sum arrays**

Given a target sum s, count the starting numbers k for which a consecutive increasing array [k, k+1, ...] sums to exactly s. Example: s = 10 gives [1,2,3,4] and [10], so the answer is 2.

<sub>Topics: Math, Two Pointers</sub>

**Multi-table SQL query**

Join several related tables and apply filtering and aggregation to produce the required output; used JOIN, UNION, SUM, GROUP BY, ORDER BY, SEC_TO_TIME, FORMAT and CONCAT.

<sub>Topics: SQL</sub>

**Logistic regression in notebook**

Using scikit-learn, preprocess, clean and normalise given data and train a logistic regression for binary classification; scored on accuracy over hidden test data.

<sub>Topics: ML/AI, Python & Pandas</sub>

### Round 1

30-40 minutes.

**Thesis explanation with follow-ups**

Explain the computer vision thesis, with probing on intuition at each step.

<sub>Topics: ML/AI</sub>

**Deep learning basics**

Cross-entropy loss formula, convolution and pooling layers and their intuition, training procedure, LR scheduler, optimizer, and basic backpropagation.

<sub>Topics: ML/AI</sub>

**KNN from scratch**

Code KNN for categorical data from scratch in any language (Notepad, run on an online compiler), demonstrate with a sample input and explain the expected output.

<sub>Topics: ML/AI</sub>

**Statistics questions**

Late in the round, questions on statistics. Exact questions not given.

<sub>Topics: ML/AI, Math</sub>

### Round 2

Not described in the form.

No specific questions reported.

**Tips:** Prepare statistics for data science roles. · Keep notes on each project: data, preprocessing, architecture, loss, metrics, design reasons. · Make projects unique and explainable.

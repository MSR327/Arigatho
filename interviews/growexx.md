## 28 Dec 2025 · Jr. Software Engineer (MERN track) · on-campus

Online assessment, on-site task assignment, technical interview 1, then technical interview 2 with HR.

### Online assessment

2.5 hours; aptitude, CS fundamentals and tech-stack MCQs.

**Aptitude and CS MCQs**

Logical, verbal and quantitative aptitude plus data structures, OS, DBMS, and stack MCQs on Python, React, Node/Express, PHP and ML. Exact questions not given.

<sub>Topics: Aptitude, OS/DBMS/CN MCQ, Web Dev</sub>

### Task assignment

On-site, 2-3 hours, Google and docs allowed, AI tools not allowed.

**Parse server log file to JSON**

Parse a server logs text file and output JSON with the count of successful requests, count of error requests, payload size and a few other properties.

<sub>Topics: Strings, Other</sub>

### Technical interview 1

30 minutes, two interviewers, resume based.

**AWS deployment and Lambda**

How the candidate deployed their web app on AWS, and what AWS Lambda is.

<sub>Topics: Software Engineering</sub>

**SQL joins with GROUP BY**

Write and explain an SQL query involving multiple joins and GROUP BY.

<sub>Topics: SQL</sub>

### Technical interview 2 and HR

20 minutes rapid fire with a senior manager and HR head.

**Resume technical and HR questions**

Resume-based technical questions plus family background, motivation, strengths and weaknesses. Exact technical questions not given.

<sub>Topics: HR & Behavioral</sub>

**Tips:** Know your resume projects deeply. · Practice popular interview MCQs. · Do mock interviews to improve communication.

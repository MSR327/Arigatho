### Technical interview

About 1h20-1h30, includes presentation defence and live coding

**First and last position in sorted array**

Live-code finding the first and last positions of an element in a sorted array, optimally.

<sub>Topics: Binary Search, Arrays</sub>

**Linked list loop**

Live-code detecting a loop in a linked list.

<sub>Topics: Linked List</sub>

**Router vs Layer 3 switch, VLAN**

Difference between a router and a Layer 3 switch; what a VLAN is; how to carry traffic from different VLANs through the same gateway.

<sub>Topics: OS/DBMS/CN MCQ</sub>

**Networking basics**

Proxy servers and which type protects a company server; firewall; traceroute vs ping; HTTPS and how it secures; GET vs POST; Silly Window Syndrome and Nagle's algorithm; purpose of the frame preamble.

<sub>Topics: OS/DBMS/CN MCQ</sub>

**What happens on the network during a Webex call**

Explain what happens in the backend network while using Webex during this interview.

<sub>Topics: OS/DBMS/CN MCQ</sub>

**Core CS and Python**

ACID and transaction risks; catch vs finally; dunder methods; function of self; four pillars of OOP; basic Linux commands; virtual memory, paging and page replacement; SQL vs NoSQL and DBMS vs RDBMS.

<sub>Topics: OS/DBMS/CN MCQ, OOP</sub>

**School network scenario**

In a school, students can message each other and teachers can message each other, but teachers and students cannot reach each other's lab PCs; what would you do as network specialist.

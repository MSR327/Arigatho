## 2025-26 season · Desk Quant Analyst · IIT Kanpur · on-campus

Two online assessments (SDE and quant), then three rounds: DSA, statistics and puzzles with easy DSA, and an interview with a senior quant researcher.

### Round 1: online DSA

Three DSA problems of increasing difficulty on HackerRank.

**Longest vowel-ordered subsequence**

Hardest problem: in a given string, find the longest length of a subsequence of the form a's, then e's, then i's, then o's, then u's.

<sub>Topics: DP, Strings · Similar: [LeetCode 1839. Longest Substring Of All Vowels in Order](https://leetcode.com/problems/longest-substring-of-all-vowels-in-order/) (Medium)</sub>

### Round 2

Scheduled together with round 3.

**Statistics fundamentals**

CLT, normal distribution modelling of a problem, and area under the pdf within 1, 2 and 3 standard deviations.

<sub>Topics: Math</sub>

**Simple puzzles and easy DSA**

Simple puzzles and two easy DSA problems. Exact problems not given.

<sub>Topics: Puzzles, Arrays</sub>

### Round 3

Interview with a senior quant researcher.

**Resume and debugging reasoning**

Resume and project discussion, and hypothetical questions on debugging your own algorithm that fails for some reason.

<sub>Topics: HR & Behavioral</sub>

**Tips:** Revise statistics fundamentals and the normal distribution. · Start with CSES and pattern recognition; solve puzzle sets like Brainstellar and QuantGuide. · Find a peer group, be thorough with your resume and express observations clearly.

## 16 Oct 2025 · Software Developer · IIT Kharagpur · on-campus

Online assessment with two C++ problems, then three online technical interviews (the first two on the same day).

### Online assessment

Two C++ problems, fairly easy.

**Binary search problem**

One C++ problem using binary search. Exact problem not given.

<sub>Topics: Binary Search</sub>

**String hashing problem**

One C++ problem on string manipulation with hashing. Exact problem not given.

<sub>Topics: Strings, Hashing</sub>

### Interview 1: OOP and OS

About 1 hour, HackerRank CodePair.

**Four pillars of OOP with code**

Explain all four OOP pillars and write example code for each.

<sub>Topics: OOP</sub>

**Virtual functions, vtables, constructors**

Detailed discussion of virtual functions, vtables and constructors.

<sub>Topics: OOP</sub>

**OS theory and scheduling algorithms**

Frequently asked OS theory and scheduling algorithms.

<sub>Topics: OS/DBMS/CN MCQ</sub>

**fork() output question**

Output-based question on the fork() call.

<sub>Topics: Code Output (C/C++/Java/Python), OS/DBMS/CN MCQ</sub>

**Implement Linux file commands in C++**

Implement functions of the Linux file management system in C++, such as mkdir, ls and creating a file.

<sub>Topics: Software Engineering</sub>

### Interview 2: OS, CN, Linux, STL

About 1 hour, immediately after round 1.

**Race conditions and semaphores**

Detailed discussion of race conditions, their solutions and semaphores.

<sub>Topics: OS/DBMS/CN MCQ</sub>

**Vector and array internals in C++**

Multiple output questions on internal implementation of vectors and arrays, and stack versus heap memory.

<sub>Topics: Code Output (C/C++/Java/Python)</sub>

**Linux commands and pipe**

Explain various Linux commands and uses, plus a tricky question involving the pipe symbol.

<sub>Topics: Other</sub>

**Networks basics**

Port numbers and the OSI model.

<sub>Topics: OS/DBMS/CN MCQ</sub>

**Estimate pi in C++**

Coding question in C++ to estimate the value of pi.

<sub>Topics: Math</sub>

### Interview 3: Node.js coding and system design

Choice of JavaScript or Python; candidate chose JavaScript.

**Two-part Node.js application**

Build a Node.js application in two parts: code the first, optimise its time complexity, then code an optimised second part. Exact problem not given.

<sub>Topics: Web Dev</sub>

**Memory optimisation and system design discussion**

Verbal discussion of memory optimisation leading to horizontal and vertical sharding, load balancing, CDN and caching.

<sub>Topics: Software Engineering</sub>

**Tips:** Learn OOP and OS from GFG and course slides, with clarity. · Practise contests on Codeforces, AtCoder and LeetCode. · Learn Linux commands in combination, especially pipes.

## 2025-26 season · SDE · IIT Kanpur · on-campus

Two pre-Day-1 interview rounds.

### Round 1

Spoken DSA problems then OOP.

**Two spoken DSA questions**

Two DSA questions given orally; only the solution idea was needed (20 minutes). Exact problems not given.

<sub>Topics: Arrays</sub>

**Deep OOP questions**

Multilevel inheritance, shared pointers and similar C++ OOP topics (40 minutes).

<sub>Topics: OOP</sub>

### Round 2

Based on networking courses and an internship on the resume, then OS.

**Core networking**

OSI layers, whole packet tracing, DNS rerouting, IP addresses, tracing packet failure and recovery (40 minutes).

<sub>Topics: OS/DBMS/CN MCQ</sub>

**Core OS**

IPC, piping, user and kernel space, process versus thread resources, process running and stopping, interrupt handling, scheduler, cache management (20 minutes).

<sub>Topics: OS/DBMS/CN MCQ</sub>

## 3 Oct 2025 · Software Engineer · IIT Kharagpur · on-campus

HackerRank online assessment, then three interview rounds.

### Online assessment

HackerRank, 4 medium-hard LeetCode-style questions; different sets per candidate.

**Four medium-hard coding questions**

Topics reported were DP, two pointers with the contribution technique, DSU and greedy. Exact questions not given.

<sub>Topics: DP, Two Pointers, Greedy</sub>

### Round 1

45 minutes.

**2D grid search with changing constraints**

One ad hoc DSA question on searching a 2D grid using different techniques; the interviewer kept adding or modifying constraints after each answer. Took 20-25 minutes.

<sub>Topics: Arrays, Graphs</sub>

**OOP: virtual functions**

About 20 minutes of OOP questions, mostly around virtual functions and the virtual pointer.

<sub>Topics: OOP</sub>

### Round 2

1 hour on core CS.

**Matrix multiplication loop order and cache**

Given two loop orderings for matrix multiplication (outer two loops in row-major versus column-major form), comment on which is more optimal; then write a loop so all computation proceeds in row-major order, testing CPU cache optimization.

<sub>Topics: OS/DBMS/CN MCQ, Arrays</sub>

**Design Google Docs**

Design Google Docs and give a high-level API for it.

<sub>Topics: Software Engineering</sub>

**C++ and OS fundamentals**

Many questions on OOP, constexpr, inline optimization, internal working of virtual functions, operating systems and computer architecture (memory layout and alignment). Exact questions not given.

<sub>Topics: OOP, OS/DBMS/CN MCQ</sub>

### Round 3

1 hour.

**In-memory storage project**

High-level discussion of the candidate's custom in-memory storage (Redis-like) project, including how multiple clients and system calls were handled.

<sub>Topics: Software Engineering</sub>

**Design an order book**

Design an order book, with discussion of optimizing the design and trade-offs.

<sub>Topics: Software Engineering</sub>

**Debug a C++ snippet**

Debug a given C++ code snippet containing errors.

<sub>Topics: Code Output (C/C++/Java/Python)</sub>

**Tips:** Read about systems: learncpp.com, Berkeley OS and computer architecture courses. · Build a project with depth that gives design discussion material.

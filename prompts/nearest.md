These are coding questions from Indian campus-placement online assessments (OAs). For each one,
find the problem on a practice site that a student should solve to be ready for it.

- qid: the id in square brackets.
- problem: the closest problem you know on one of these sites: {sites}. When two are about as
  close, take the one from the site earlier in that list. For an SQL question, use LeetCode's or
  HackerRank's SQL problems.
  - site: the site's name, written as above.
  - id: LeetCode: the problem number. Codeforces: contest number and letter, e.g. 1352C.
    CSES: the task number in its link. AtCoder: the task id, e.g. abc123_d. GeeksforGeeks: the
    problem's name in its link, e.g. trapping-rain-water. HackerRank: the challenge's name in its
    link, e.g. maximum-subarray-sum. CodeChef: the problem code.
  - title: the problem's exact title on that site.
  - how: "same" if it is the same problem, "variant" if the core task is the same but the story
    or limits differ, "idea" if it is a different problem solved with the same main idea.
  - why: what the two share, in at most 10 words, e.g. "monotonic deque over a sliding window".
  The problem need not be the same: when there is no same problem, give the nearest one solved
  with the same main idea, so that practising it prepares the student. A question whose task is
  clear, even if only from its title, almost always has one.
  Use null only if the question is not a coding or SQL-query problem (an MCQ, theory, a
  code-output question), or if it does not say what it asks (e.g. "one hard DP question").
  Only name problems you are sure exist: every one is checked on the site, and a wrong one is
  dropped.

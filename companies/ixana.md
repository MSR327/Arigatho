## 2026-11-08 · IIT BHU · FTE · Embedded · Other round

### Q1. Ixana embedded hiring process

Three practical rounds plus a final round:
- Assignment: a take-home coding task in C or Python, checking memory optimization and buffer handling.
- Technical Round 1: C programming, firmware debugging and hardware memory constraints.
- Technical Round 2: digital electronics, such as D flip-flops, drawing waveforms, setup/hold time (static timing analysis).
- Final Round: validation of the resume's hardware/embedded projects and basic concepts.

Another student said they had heard a GitHub repo is given.

### Q1. Minimum jumps to reach the end

Given an array arr of size n, start at index 0. From any index i, you can jump to any index from i + 1 to min(i + arr[i], n - 1).
Find the minimum number of jumps required to reach the last index.

### Q2. Count word occurrences in a grid

You are given a 2D character grid grid of size n*n and a string word.
Find the total number of occurrences of word in the grid, subject to the following rules:
- You can start from any cell in the grid.
- You can move in any of the 8 directions: horizontally, vertically, or diagonally.
- Once you start moving in a direction, you must continue in the same direction until the word is formed.
- You cannot change direction while matching the word.
- If the word is a palindrome, count occurrences in both directions separately.
Return the total number of occurrences.

### Q3. Most popular nodes with popular neighbours

You are given an undirected graph with N nodes and M edges.
The influence of a node is its degree (number of directly connected nodes).
1. Find all nodes having the maximum degree.
2. For each such node, consider the degrees of its adjacent nodes.
3. Out of these maximum degree nodes, Return only those maximum-degree nodes whose adjacent nodes have the same maximum influence.

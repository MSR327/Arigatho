### Q1. Modulo Sum Function

Given a function C(i, j) = (i mod j) + (j mod i) for integers i and j, find f(n) = Σ(i=1..n) Σ(j=1..n) C(i, j) for a given n.

The core holding the latch can either assign the current operation to itself, which passes the latch to the other core, or assign the operation to the other core and keep the latch. Example 1: Input [141, 592, 653] -> Output [733, 653] (Core 1 gives away 141 and keeps the latch, then runs 592 itself; the latch passes to Core 2, which runs 653).

### Q1. Tree: visit all required nodes, start at 1 and end at n

You are given an unweighted, undirected, unrooted tree with n nodes numbered 1 to n.

You must start at node 1, visit every node in `visitNodes`, and finally end at node n. You may visit any node multiple times. Find the minimum number of edges traversed.

Constraints:

```
1 <= n <= 10^5
|visitNodes| <= n - 2
Nodes 1 and n are guaranteed not to be in visitNodes.
```

Example:

```
      1
     / \
    2   3
   / \   \
  4   5   6

n = 6, visitNodes = [4, 6]
One optimal walk: 1 -> 2 -> 4 -> 2 -> 1 -> 3 -> 6 (6 edges)
Answer: 6
```

The poster's solution idea: answer = 2E - D, where E is the number of edges in the minimal subtree containing 1, n and all required nodes, and D is the distance from 1 to n. (The code in the message was cut off.)

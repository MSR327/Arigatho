### Q1. Minimum cost to remove special nodes in 2^N segment

Given an integer N (N ≤ 30), consider a segment containing 2^N nodes, some of which are special nodes. We need to remove all nodes while minimizing the total cost. The following operations are allowed:

1. Remove the entire segment: if the segment contains `count` special nodes and has length `len`, the cost is `P × count × len`.
2. Empty segment: if the segment contains no special nodes, the cost is `Q`.
3. Divide the segment: if the segment length is even, divide it into two equal halves and recursively calculate the cost of both halves. The total cost is the sum of their costs.

Task: Find the minimum possible cost to remove all special nodes.

### Q3. Directed weighted graph queries with stop constraints

Given a directed weighted graph, answer multiple queries of the form `(u, v, stops)`. For each query, find the minimum cost to travel from node u to node v, subject to the given stop constraint.

Constraints:
- Number of nodes: N ≤ 100
- Number of queries: Q ≤ 2 × 10^5
- Maximum allowed stops: stops ≤ 10

Task: Efficiently process all queries and return the minimum travel cost for each query, respecting the maximum number of allowed stops.

### Q3. Top track from 'TrackName@score' logs

Section 3: DSA (1 question). You are given an array of string logs in the format "TrackName@score". Parse each log and add its score to that track's total. Scores can be negative. Ignore invalid logs: a log is invalid if it has no '@', if the score is not a number (e.g. "TrackName@abc"), or if the score is missing. A track is eligible only if it appears in at least 3 valid logs. Return the eligible track with the highest total score. If several tracks tie for the highest score, return the lexicographically smallest name.

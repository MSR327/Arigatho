### Q1. Players who can still win the trophy

Given an array of size n (n up to 10^5) with the scores of n people before the final race. In the final race the person who comes first gets n points, second n-1, and so on, last gets 1 point (no ties). After the race, all players with the highest score get a trophy. Find the number of people who have a chance of winning the trophy.

Example: n=5, points=[12,14,14,15,15] gives output 4, since player 1 cannot win even if they win the race: max 12+5 = 17, but the highest score would be at least 18.

## 2026-11-11 · IIT Bombay · FTE

### Q1. Sync engine: queries affected by each write

Variant of the "sync engine" question (ticketing system variant).

Input format:
- First line has 2 integers `n`, `q`.
- `n` query blocks follow (numbered 1 to n in input order). Each block is: a line with the table name, a line with an integer `T` (number of nodes in the condition tree), then `T` lines describing nodes 1 to T, where node 1 is the root.
- Each node line is one of:
  - `AND k c1 c2 …`
  - `OR k c1 c2 …`
  - `COND column= value`
- Then `q` write blocks follow. Each starts with the write type and table name (for example INSERT, DELETE, UPDATE), then a row: an integer `c` followed by `c` lines of `column value`.

Output: print `q` lines. Line `i` contains the ids of the queries affected by the i-th write, in increasing order, space separated. If no query is affected, print `-1`.

Note: the poster only gave the input/output format; the exact matching rules for when a write affects a query are not stated.

### Q3. Stacked Cuboid Coverage

Time Limit: 1.0 second, Memory Limit: 256 megabytes.

You are given N rectangular cuboids stacked vertically one on top of another, ordered from 1 (bottom-most) to N (top-most), without any vertical gaps.

The i-th cuboid has dimensions L_i x W_i x 1. All cuboids are aligned along a common vertical corner axis; the i-th cuboid spans [0, L_i] along x, [0, W_i] along y, and [i-1, i] along z.

In isolation, a single cuboid requires a number of covering unit cubes equal to its total surface area.

When the i-th cuboid is placed directly on top of the (i-1)-th, they share a horizontal rectangular contact region of area O_i. Due to the hidden contact faces and the shared step boundary, each adjacent contact region reduces the total number of unit cubes required by 3 * O_i.

Calculate the minimum number of unit cubes required to cover the entire resulting 3D structure, including the bottom face of the first cuboid.

Input:
- First line: integer N (1 <= N <= 2*10^5).
- Next N lines: two integers L_i and W_i (1 <= L_i, W_i <= 10^6), from bottom (i = 1) to top (i = N).

Output: a single integer (the rest of the statement was cut off in the message). The formulas for surface area and O_i were also not included.

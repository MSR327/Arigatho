### Q1. Minimum Score of a Path Between Two Cities

Shared as one of the questions in the Visa SWE intern OA ("Minimum Path Score Between Cities"); matches LeetCode 2492. You are given n cities numbered 1 to n and a 2D array roads where roads[i] = [a, b, distance] is a bidirectional road between a and b with the given distance. The cities graph is not necessarily connected. The score of a path is the minimum distance of any road on that path. Return the minimum possible score of a path between cities 1 and n. A path may contain the same road or city multiple times, including cities 1 and n. It is guaranteed that there is at least one path between 1 and n. Constraints: 2 <= n <= 10^5, 1 <= roads.length <= 10^5, 1 <= distance <= 10^4. Example: n = 4, roads = [[1,2,9],[2,3,6],[2,4,5],[1,4,7]] -> 5.

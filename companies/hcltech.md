### Q1. HCLTech 2027 batch OA and hackathon format

**Online assessment:**
- Aptitude: Quantitative, Logical, Verbal
- Technical MCQs: OOPS, DBMS, OS, CN
- Berrybot AI Assessment: resume/JD-based questions, Java DSA coding, React coding
- Duration varies by drive.

**Hackathon** (usually after training in some drives): choose 1 problem statement from given options, build a working application, explain code, logic and tech stack; individual technical evaluation; basic HR round may follow.

Prepare: Arrays, Strings, HashMap, Java/OOPS, SQL, DBMS, React, JavaScript, projects and REST APIs.

## 2026-11-13 · NIT Surathkal · FTE

### Q1. Moneyview two-round Linux/networking assessment

Two rounds focused on Linux, systems, networking and server-side concepts.

Round 1: practical Linux tasks directly in the terminal, e.g. change a server's port number when it was misconfigured, identify and fix missing port configurations, edit files exclusively through the terminal, and correct syntax errors in Python files using command-line tools. About sixty candidates advanced.

Round 2: online assessment on a Linux environment (WSL/Linux or lab computers), entirely server-focused, implementing practical networking applications: (1) build a UDP echo server; (2) build a key-value store supporting set, get and update; (3) multithreading tasks; (4) a later problem on communication between nodes, likely a gossip-based mechanism. Detailed documentation was provided; socket programming understanding was essential and language choice was free. After the assessment, interviewers asked individually about implementations and approaches.

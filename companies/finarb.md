## 2026-11-19 · IIT BHU · FTE

### Q1. Finarb OA format: Linux terminal tasks

The online assessment had two rounds focused heavily on Linux, systems, networking and server-side concepts. In the first round, candidates worked on practical Linux tasks directly in the terminal: basic Linux commands, file editing and system administration. Tasks included:

- Changing a server's port number when it was misconfigured
- Identifying and fixing missing port configurations
- Editing files exclusively through the terminal
- Correcting syntax errors in Python files using command-line tools

The second round is not described.

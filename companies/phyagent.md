## 2026-11-12 · IIT Guwahati · FTE

### Q1. Fruit Into Baskets

Given an integer array fruits where fruits[i] is the type of fruit at position i. You have two baskets, each holding only one type of fruit. You can collect fruits starting from any index, but from consecutive positions. Find the maximum number of fruits you can collect with at most two distinct types.

Example:
```
Input: fruits = [1, 2, 1, 2, 3]
Output: 4
```
The subarray [1, 2, 1, 2] contains only two distinct fruit types.

Expected approach: Sliding Window + HashMap.

### Q2. Maximum Number of Strings

You are given a vector of binary strings strs, along with two integers maxZ and maxOnes. Select a subset of strings such that the total number of 0s across selected strings does not exceed maxZ and the total number of 1s does not exceed maxOnes. Find the maximum number of strings that can be selected. Each string can be selected at most once.

Example:
```
strs = ["10", "0001", "111001", "1", "0"]
maxZ = 5
maxOnes = 3
Output: 4
```
Select ["10", "0001", "1", "0"]: total zeros = 4, total ones = 3.

## 2026-11-12 · IIT Roorkee · FTE · SDE

### Q1. Players who can still win the trophy

Given an array of size n (n up to 10^5) with the scores of n people before the final race. In the final race the person who comes first gets n points, second gets n-1, and so on, the last gets 1 point (no ties). After the race, all players with the highest score get a trophy.

Find the number of players who still have a chance of winning the trophy.

Example:
```
n = 5, points = [12, 14, 14, 15, 15]
output = 4
```
Player 1 cannot win even if he wins the race: max 12+5 = 17, but the highest score would be at least 18.

### Q1. Gas station circular tour

Given two integer arrays, `gas` and `cost`, representing the fuel available at each gas station and the fuel required to reach the next station on a circular route, find the starting station index from which you can complete one full clockwise circuit with an initially empty tank. Return -1 if no solution exists. If a solution exists, it is unique.

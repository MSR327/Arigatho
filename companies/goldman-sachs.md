### Q2. Nearest city sharing x or y coordinate

Given an array of strings `city` (city names) and two 1-D arrays `x` and `y` with the coordinates of the cities, in order (city[0], x[0], y[0] describe the first city). Answer m queries: for each query a city name is given, and you must return a city that has either the same x or the same y coordinate as the queried city and is at the shortest possible distance from it. If multiple such cities exist, return the lexicographically smallest one. If no city shares x or y with the queried city, return "NONE".

Constraints:
- n (number of cities) and m (number of queries) <= 10^5
- Length of city name <= 10
- All cities have unique coordinates

## 2026-11-08 · IIT BHU · FTE · Quant Analyst

### Q1. Goldman Sachs Quant Analyst OA pattern

HackerRank OA of around 97 minutes, in three parts:

- Software Fundamentals: data structures, algorithms and complexity.
- Software Diagnostics: debugging codebases (such as Django, Spring Boot or Node.js). A built-in, limited AI assistant is allowed here; external AI tools and extensions are banned.
- Quantitative Math: MCQs on probability, statistics, linear algebra and calculus.

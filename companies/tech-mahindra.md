### Q1. Allocate Mailboxes (LeetCode 1478)

LeetCode 1478. Given the array houses where houses[i] is the location of the i-th house along a street and an integer k, allocate k mailboxes in the street. Return the minimum total distance between each house and its nearest mailbox.  
Example 1: houses = [1,4,8,10,20], k = 3 -> 5 (mailboxes at 3, 9, 20).  
Example 2: houses = [2,3,5,12,18], k = 2 -> 9.  
Constraints: 1 &lt;= k &lt;= houses.length &lt;= 100; 1 &lt;= houses[i] &lt;= 10^4; all values of houses are unique.

### Q2. Cherry Pickup (LeetCode 741)

LeetCode 741. You are given an n x n grid representing a field of cherries; each cell is 0 (empty, can pass through), 1 (a cherry you can pick up and pass through), or -1 (a thorn that blocks the way). Return the maximum number of cherries you can collect by: starting at (0,0) and reaching (n-1,n-1) by moving right or down through valid cells (0 or 1); then returning to (0,0) by moving left or up through valid cells. When passing through a cell with a cherry you pick it up and the cell becomes 0. If there is no valid path between (0,0) and (n-1,n-1), no cherries can be collected.  
Example: grid = [[0,1,-1],[1,0,-1],[1,1,1]] -> 5.  
Example: grid = [[1,1,-1],[1,-1,1],[-1,1,1]] -> 0.  
Constraints: 1 &lt;= n &lt;= 50; grid[i][j] is -1, 0 or 1; grid[0][0] != -1; grid[n-1][n-1] != -1.

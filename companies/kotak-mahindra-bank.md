## 2026-11-12 · IIT BHU · FTE · Data Scientist

### Q1. Kotak Data Scientist OA topics

Topics covered:

1. Python: lists, dictionaries, strings; NumPy & Pandas; data manipulation
2. SQL: joins, subqueries; GROUP BY, HAVING; window functions
3. Statistics: probability; hypothesis testing; mean, median, variance; A/B testing
4. Machine Learning: regression & classification; decision trees; random forest; overfitting & underfitting; model evaluation
5. Coding: array & string problems; hashing; basic DSA; data processing
6. Data Interpretation: business case studies; charts & numerical analysis

Difficulty: moderate (role-dependent).

## 2026-11-11 · NIT Kurukshetra · FTE · Data Scientist – Analytics, AI/ML & GenAI

### Q1. Kotak Data Scientist OA pattern and syllabus

The Online Assessment generally has five sections:
- Abstract Reasoning: figure patterns, visual sequences, logical pattern recognition.
- Quantitative Aptitude: percentages, averages, ratios, profit and loss.
- Logical Reasoning: directions, blood relations, seating arrangements.
- Data Interpretation: tables, charts, graphs and calculations.
- Technical: Python, SQL, Hive, Apache Spark and machine learning.

Technical focus: SQL JOINs (INNER, LEFT, RIGHT, FULL OUTER) with output tables and NULLs; Python try-except-finally, file handling, lambda functions, output-based questions; HiveQL basics, Spark RDD transformations vs actions, filtering, sorting; ML: K-Means, SVM, neural networks, regression, evaluation metrics (accuracy, precision, recall, F1), bias-variance trade-off.

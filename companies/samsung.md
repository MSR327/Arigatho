## 2026-10-13 · IIT Delhi · FTE

### Q1. Machine manufacturing time: initialize, add, subtract, calculate

There are n machines, each with a time to manufacture a product and a unique id.

Write pseudo code for implementing the following functions:

1. `initialize(arr[] time, arr[] id)`: initialize all machines with ids and times.
2. `add(t, id)`: add a new machine whose time is t. If the id is already present, replace its time with t. Return the number of machines.
3. `subtract(k)`: remove k machines. Remove in order of larger time first; if the time is the same, remove the one with the higher id first. Return the id with the highest time after removing.
4. `calculate(M)`: return the minimum time to manufacture M machines.

(This was the Samsung R&D Noida OA; exact constraints were not given.)

### Q1. Cherry Pickup II (LeetCode 1463)

LeetCode Cherry Pickup II: You are given a rows x cols matrix grid where grid[i][j] is the number of cherries in cell (i, j). Robot #1 starts at (0, 0) and Robot #2 starts at (0, cols-1). From cell (i, j) a robot can move to (i+1, j-1), (i+1, j) or (i+1, j+1). A robot picks up all cherries in each cell it passes; if both robots are in the same cell, only one of them takes the cherries. Robots cannot move outside the grid, and both must reach the bottom row. Return the maximum total number of cherries the two robots can collect. Constraints: 2 <= rows, cols <= 70, 0 <= grid[i][j] <= 100.

Topics: DP, Arrays

### Q2. Task Scheduler (LeetCode 621)

LeetCode Task Scheduler: You are given an array of CPU tasks, each labeled with a letter A to Z, and a cooling interval n. Each CPU interval can either run one task or be idle. Two tasks with the same label must be at least n intervals apart. Return the minimum number of CPU intervals needed to finish all tasks. Example: tasks = ["A","A","A","B","B","B"], n = 2 -> 8 (A -> B -> idle -> A -> B -> idle -> A -> B). Constraints: 1 <= tasks.length <= 10^4, 0 <= n <= 100.

### Q2. Count Minimum Operations

You are given an integer array distance of length n, where distance[i] is the distance travelled by the i-th vehicle, and an integer array targetDistance of length q. In one operation you can increase or decrease any vehicle's distance by 1. For each target, find the minimum number of operations needed to make every vehicle's distance equal to that target. The original distances are restored before the next target is processed. Function: countMinimumOperations(distance, targetDistance). Example: distance = [50, 55, 60], targetDistance = [60, 55, 50, 65] -> output [15, 10, 15, 30]. Target 60: |50-60| + |55-60| + |60-60| = 15; Target 55: 10; Target 50: 15; Target 65: 30.

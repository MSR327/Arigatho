### Q1. Count pairs whose concatenation can form a palindrome

Given a vector of `n` strings, count the total number of pairs `(i, j)` such that after rearranging the concatenation of the i-th and j-th strings, it forms a palindrome. Solve in order of n.

Constraints:
- sum of lengths of all strings <= 1e5
- length of each string <= 26 (a bitmask map can be used)

Shared approach: keep a 26-bit parity mask per string; a pair works if the XOR of masks has at most one set bit. Use a hashmap of seen masks and check the same mask and `mask ^ (1<<k)` for k in 0..25.

<sub>Topics: Hashing, Bit Manipulation, Strings · Same idea: [LeetCode 1930. Unique Length-3 Palindromic Subsequences](https://leetcode.com/problems/unique-length-3-palindromic-subsequences/) (Medium), letter parity bitmask for palindrome checks · Source: [chat, 9 Nov](../archive/microsoft-oa/2026-11.jsonl#L16), [chat, 9 Nov](../archive/microsoft-oa/2026-11.jsonl#L17), [chat, 9 Nov](../archive/microsoft-oa/2026-11.jsonl#L18) · Also asked at: IIT Guwahati ×2 (last 2026-11-10)</sub>

### Q2. Count Minimum Operations

You are given an integer array distance of length n, where distance[i] is the distance travelled by the i-th vehicle, and an integer array targetDistance of length q. In one operation you can increase or decrease any vehicle's distance by 1. For each target, find the minimum number of operations needed to make every vehicle's distance equal to that target. The original distances are restored before the next target is processed. Function: countMinimumOperations(distance, targetDistance). Example: distance = [50, 55, 60], targetDistance = [60, 55, 50, 65] -> output [15, 10, 15, 30]. Target 60: |50-60| + |55-60| + |60-60| = 15; Target 55: 10; Target 50: 15; Target 65: 30.

## 2026-11-09 · IIT Guwahati · FTE

### Q1. Round 2: AI vibe coding round

A 30-minute AI vibe coding round. Candidates were asked to find the solution using an AI assistant and submit it. A randomly generated bug was then introduced in their own code, and they had to fix it without using AI.

## 2026-11-08 · IIT Guwahati · FTE · Data Engineer

### Q1. IDFC round 2 technical OA format

Round 2 (technical OA): 3 Python questions and 1 SQL question (hard). The Python questions were somewhat project-oriented, using pandas and numpy. One of the Python questions was a normal DSA question of medium to hard level.

### Q1. IDFC First Bank OA pattern

Assessment consists of 2 back-to-back tests (chain assessment):
1. Aptitude Test - 50 minutes
2. Psychometric Test - 15 minutes

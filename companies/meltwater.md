### Q3. The Bounded Substream

You are given an infinitely large 1-D grid in which every position starts empty. You receive N commands; each gives a very large index and a character ('*' or a lowercase letter a-z) to place there. Whenever placing a character completes a bounded alphabet substring, print that alphabet substring immediately on a new line. A bounded alphabet substring matches the pattern *(alphabets)*, where (alphabets) is entirely contiguous lowercase letters with no empty spaces, immediately bounded by '*' on the left and on the right. Indices can be up to 10^18, so plain arrays cannot be used. Input: the first line is N; each of the next N lines is 'index character' (index is a 64-bit integer). Output: each time a fully bounded alphabet substring is formed, print its letters without the asterisks. Constraints: 1 <= N <= 10^5; 1 <= index <= 10^18; character in {*, a..z}; commands arrive in any order (indices are not sorted or contiguous); an index is never overwritten with a different character. Example input: 7 / 629464829 * / 629464831 * / 629464830 a / 1 * / 3 c / 2 b / 4 *. Output: a / bc. (The message's explanation is cut off.)

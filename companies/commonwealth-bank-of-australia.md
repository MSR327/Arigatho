### Q4. Path sum in grid preferring downward moves

Given a 2D array of size n*n. Start at (0,0) and go to the end (n-1,n-1). You can move either right or down at any index. If you can move in both directions, prefer downward movement. For this path from start to end, calculate the total sum of the values you cross while moving from start to end.

Example:

```
Input:
n = 4;

int arr[4][4] = {
    {1,  2,  0,  4},
    {5,  6,  7,  0},
    {0,  8,  9,  10},
    {11, 0, 12, 13}
  }
Output:
1+5+6+8+9+12+13=54
```

The example path is not strictly always-down-first as stated (it moves right at some points); the exact rule for choosing the direction was not fully clear from the poster.

## 2026-10-23 · Unknown · FTE

### Q1. Zscaler CodeSignal OA format

Zscaler OA held on CodeSignal on 2026-10-23.

- Score is given out of 600 and the marks are hidden from candidates.
- Around 3-4 questions in about 2 hours. One poster got 3 questions and used the whole 2 hours; another saw 4 questions.
- 2 questions are mandatory in Python. The other two can be done in C, C++, Go or Java. The C++ version available was reported to be too old.
- The backend questions are an "AI coding round" style: implement functions and create new files.
- One poster's first question had a computer networks plus Linux flavour.

The exact problem statements were not shared.

## 2026-10-17 · SVNIT Surat · FTE · Interview

### Q1. Zscaler on-campus interview round 1

On campus it was easy. Shortlisting was random, then there were 2 rounds. Round 1:

- Intro, then basic OOPs/logic questions such as copy constructor and pointers.
- 2 easy LeetCode-type DSA questions.
- Code a linked list from scratch.
- How to make a queue using an array.
- How a 2D pointer works.
- How a hashmap works.
- What a binary tree and a balanced binary tree are, with time complexity of insert, delete, etc.

The exact DSA questions were not given.

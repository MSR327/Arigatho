## 2026-10-18 · IIIT · FTE

### Q1. Zscaler OA format

The OA is taken online on your own computer. It has 4 coding questions (reported as "I guess"): 2 DSA questions that must be solved in Python (mandatory) and 2 in any preferred language. The questions are mostly implementation based and data structure heavy.

## 2026-10-17 · SVNIT Surat · FTE · Interview

### Q1. Zscaler on-campus interview round 1

On campus it was easy. Shortlisting was random, then there were 2 rounds. Round 1:

- Intro, then basic OOPs/logic questions such as copy constructor and pointers.
- 2 easy LeetCode-type DSA questions.
- Code a linked list from scratch.
- How to make a queue using an array.
- How a 2D pointer works.
- How a hashmap works.
- What a binary tree and a balanced binary tree are, with time complexity of insert, delete, etc.

The exact DSA questions were not given.
